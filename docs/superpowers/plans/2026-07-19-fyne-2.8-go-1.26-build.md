# Fyne 2.8 and Go 1.26 Windows Build Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build both Windows applications with Fyne 2.8.0 and Go 1.26.5 while automatically selecting the working 64-bit TDM MinGW compiler.

**Architecture:** Keep compiler discovery inside `build.ps1`, but validate the target reported by every GCC candidate and order the known-working TDM compiler before the incompatible MSYS2 GCC 16 installation. Preserve explicit compiler overrides and update the Go module metadata and dependency graph without changing application behavior.

**Tech Stack:** PowerShell 5.1, Go 1.26.5, Fyne v2.8.0, CGO, TDM-GCC-64 10.3.0, Windows PE executables

## Global Constraints

- Use stable Fyne v2.8.0.
- Declare Go 1.26 in `go.mod` and verify with Go 1.26.5.
- Automatically avoid the 32-bit Simcenter compiler and incompatible MSYS2 UCRT GCC 16.1.0.
- Preserve `-CCPath` and `-CXXPath` overrides.
- Invoke the build script through a process-scoped PowerShell execution-policy bypass.

### Task 1: Safe compiler resolution

**Files:**
- Modify: `build.ps1`

**Interfaces:**
- Consumes: optional `-CCPath` and `-CXXPath` string parameters and local GCC executable paths
- Produces: validated absolute `CC` and `CXX` environment values targeting `x86_64-w64-mingw32`

- [x] **Step 1: Reproduce the automatic-selection failure**

Run:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Target fynehmi -OutputDir bin\compiler-regression
```

Expected before the fix: output selects `C:\msys64\ucrt64\bin\gcc.exe` and ends with `runtime/cgo` exit status 2.

- [x] **Step 2: Validate each compiler candidate and prioritize TDM GCC**

Add a `Test-MingwCompiler` helper that executes `-dumpmachine` and accepts only a successful result matching `^x86_64.*mingw`. Make an invalid requested path or target throw a precise error, call the helper for every hard-coded and `PATH` candidate, and order candidates as follows:

```powershell
@(
    "C:\TDM-GCC-64\bin\gcc.exe",
    "C:\msys64\ucrt64\bin\gcc.exe",
    "C:\msys64\mingw64\bin\gcc.exe"
)
```

- [x] **Step 3: Verify automatic selection and the explicit override**

Run:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Target fynehmi -OutputDir bin\compiler-regression
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Target mockserver -OutputDir bin\compiler-regression -CCPath C:\TDM-GCC-64\bin\gcc.exe -CXXPath C:\TDM-GCC-64\bin\g++.exe
```

Expected: both commands exit 0 and print the TDM GCC and G++ paths.
